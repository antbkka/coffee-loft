# 🖼 Папка с локальными изображениями

Здесь лежат все фотографии, которые используются на сайте. По умолчанию здесь лежат **SVG-плейсхолдеры** (с расширением `.jpg`, но внутри это валидный SVG с тёмным фоном и подписью имени файла).

## Как заменить плейсхолдер на своё фото

Просто замените файл с тем же именем. Например:

```bash
# Удалить плейсхолдер и положить реальное фото
del public\images\latte.jpg
copy D:\my-photos\my-latte.jpg public\images\latte.jpg
```

Поддерживаются форматы **JPG, PNG, WebP**. Для оптимальной производительности рекомендуется WebP или JPG с качеством 80%.

## Если нужны дополнительные изображения

1. Положите файл в эту папку
2. Пропишите путь `/images/ваш-файл.jpg` в нужном компоненте или в `src/data/menu.js`

## Оптимизация

Для продакшена рекомендуется:

- Сжимать через [Squoosh](https://squoosh.app/) или `sharp`
- Конвертировать в WebP (на 25–35% легче при том же качестве)
- Использовать `loading="lazy"` (уже добавлено в компонентах)

## Если хотите вернуть Unsplash

Просто замените путь `/images/...` обратно на полный URL в файле `src/data/menu.js` (для меню/команды/галереи) или прямо в JSX-файлах страниц (для hero/CTA/map/booking фонов).
