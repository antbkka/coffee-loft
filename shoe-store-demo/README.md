# FORMA — концепт интернет-магазина обуви

Минималистичный демонстрационный storefront на React + Vite. Проект подготовлен как портфолио-кейс и для демонстрации заказчику.

## Возможности

- Адаптивная главная страница и каталог.
- Фильтрация по категориям, поиск и сортировка по цене.
- Карточки товаров, выбор размера, избранное.
- Корзина с изменением количества и подсчётом суммы.
- Демонстрационное оформление заказа без реальной отправки.
- Форма подписки с клиентским подтверждением.
- Мобильная навигация и адаптация под небольшие экраны.

## Запуск локально

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Деплой на Vercel

1. Импортировать репозиторий GitHub.
2. Указать Root Directory: `shoe-store-demo`.
3. Framework Preset: Vite.
4. Build Command: `npm run build`.
5. Output Directory: `dist`.
6. Environment Variables не требуются.

## Демонстрационные ограничения

Это frontend-концепт. Товары, цены, остатки и изображения — демонстрационные. Корзина работает в состоянии React, заказ не отправляется в CRM или магазин. Реальная оплата, доставка СДЭК/Почта России, складской учёт, серверная админ-панель и юридические страницы не подключены.

Изображения загружаются с Unsplash. Для коммерческого запуска нужно заменить демо-контент на материалы и фотографии заказчика и проверить лицензии/условия использования изображений.
